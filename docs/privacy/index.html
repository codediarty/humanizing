개인정보처리방침

시행일 2026년 11월 21일 · 운영 성균관컨설팅

1. 처리하지 않는 정보

한국휴머나이징은 회원가입이 없습니다. 이용자가 넣은 글과 올린 파일은 검사와 휴머나이징에만 쓰고 저장하지 않으며, 파일에서 글을 꺼내는 일은 이용자의 브라우저 안에서 합니다. 결제 수단 정보는 받지 않습니다.

2. 처리하는 정보와 목적

  • 토큰 결제 · 코드 발송: 결제할 때 결제처(성균관컨설팅 결제 페이지)에 적은 이름 · 이메일 · 주문 정보를 토큰 코드 발송과 결제 확인, 환불 처리에 씁니다. 거래 기록은 전자상거래법에 따라 5년 보관합니다.
  • 토큰 코드: 운영사 서버에는 코드의 해시와 남은 토큰 · 사용 기록만 남깁니다. 원래 코드는 저장하지 않습니다.
  • 서비스 안정: 요청 횟수를 제한하려고 이용자의 브라우저가 만든 임의 식별값과 요청 시각을 잠시 처리합니다.
  • 이 브라우저 저장: 토큰 코드와 결제하러 가는 동안 하던 글은 이용자의 브라우저(로컬 저장소)에만 저장되며, 하던 글은 24시간 뒤 지워집니다.

3. 처리 위탁 · 국외 이전

서버 운영에 Google Workspace(Apps Script · Gmail, 미국)를 이용하며, 결제는 성균관컨설팅 결제 페이지와 결제 대행사가 처리합니다. 사이트는 GitHub Pages(미국)로 서빙합니다.

4. 이용자의 권리

이용자는 자기 정보의 열람 · 정정 · 삭제 · 처리 정지를 token@humanizing.ai.kr로 요청할 수 있으며, 운영사는 지체 없이 처리합니다.

5. 파기

보관 기간이 끝난 정보는 지체 없이 복구할 수 없는 방법으로 지웁니다.

6. 개인정보 보호책임자

성균관컨설팅 대표 이채연 · token@humanizing.ai.kr

7. 고지

이 방침이 바뀌면 적용 7일 전부터 이 페이지에 알립니다.
