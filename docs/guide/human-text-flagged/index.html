왜 사람 글이 AI로 나올까

탐지기는 누가 썼는지가 아니라 문장이 어떤 모습인지를 봅니다. 공문서나 논문처럼 정해진 틀을 따르는 글, 같은 끝맺음이 이어지는 글, 문장 길이가 고른 글은 사람이 써도 점수가 높게 나올 수 있습니다. 놓치는 AI 글을 줄이려고 기준을 엄격하게 잡은 탐지기일수록 더 그렇습니다.

오탐을 줄이는 방법

  • 표시된 문장의 끝맺음과 연결어를 바꿔 보세요.
  • 일반론 문장에 내 자료의 숫자나 사례를 더하세요.
  • 짧은 문장과 긴 문장을 섞어 리듬을 바꾸세요.

한국휴머나이징으로 표시된 문장만 휴머나이징해도 같은 효과를 얻을 수 있습니다.

쓴 과정을 남겨 두세요

초안 파일, 수정 기록, 참고 자료 목록을 남겨 두면 판정에 이의를 제기해야 할 때 도움이 됩니다.

오탐이 잦은 글과 대처

글오탐이 잦은 까닭대처
공문 · 보도자료정해진 서식과 표현을 따름서식 문구는 두고, 설명 문장의 길이와 끝맺음을 섞기
공학 실험 보고서절차를 같은 꼴로 늘어놓음숫자는 그대로, 고찰 문단에 내 실험에서 생긴 일 적기
법령 · 규정 해설조문 표현을 따라 씀조문 인용은 그대로, 해설은 사례로 풀기
영어 논문을 옮긴 원고번역투가 남음주어를 앞으로, 피동문을 능동문으로

쓴 과정, 이렇게 남겨 두세요

  1. 문서 프로그램의 버전 기록이 남도록 한 파일에서 이어 씁니다.
  2. 자료를 찾을 때 메모와 링크를 따로 모아 둡니다.
  3. 초안을 날짜별로 저장합니다.
  4. 남의 글을 옮긴 곳은 처음부터 출처를 달아 둡니다.

자주 묻는 질문

오탐이면 휴머나이징하지 않아도 되지 않나요?

판정은 숫자로 남기 때문에, 표시된 문장을 다듬어 두면 불필요한 오해를 줄일 수 있습니다.

어떤 글이 오탐이 잦나요?

정해진 틀을 따르는 보고서, 연구 계획서, 공문서 형식의 글에서 잦습니다.
